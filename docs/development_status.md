# 말랑이의 정복 개발 현황

- 정리일: 2026-10-15
- 엔진: Godot 4.7.2
- 현재 단계: 코어 게임 흐름 구현 완료, 픽셀아트 적용 전
- 다음 실기기 테스트: 아트 적용과 남은 개발을 마친 뒤 진행

이 문서는 지금까지 확정한 내용과 실제 구현 상태를 빠르게 확인하기 위한 인계 문서다.
세부 게임 규칙은 `game_design.md`, 화면과 자산 규격은 `ui_art_plan.md`와
`pixel_art_checklist.md`, 코드 관리 원칙은 `project_guidelines.md`를 기준으로 한다.

## 1. 현재 게임의 방향

`말랑이의 정복`은 Conway의 Game of Life를 이용한 세로형 모바일 영토 전략 게임이다.
광고, 구독과 인앱 결제 없이 한 번 구매하면 모든 콘텐츠를 플레이할 수 있는 작은 완결형
게임을 목표로 한다.

플레이어는 패턴 네 개로 덱을 구성하고 라운드마다 말랑력을 소비해 패턴을 배치한다.
배치를 확정하면 양 진영의 셀이 자동으로 15세대 동안 진화하며, 셀이 지나간 영토가
누적된다. 마지막 라운드 종료 시 더 많은 영토를 가진 진영이 승리한다.

진행 구조는 세계지도 정복형이 아니라 록맨식 스테이지 선택형이다. 처음부터 여덟 명의
라이벌을 자유로운 순서로 상대할 수 있고, 모두 격파하면 중앙의 최종 라이벌이 열린다.
정복 서사보다 패턴과 스킨을 바꿔가며 반복해서 실험하는 장난감 같은 경험을 우선한다.

## 2. 확정된 콘텐츠

### 패턴과 덱

- Game of Life 패턴 총 12종
- 시작 패턴 3종: Block, Blinker, Glider
- 라이벌 최초 승리로 패턴 9종을 하나씩 확정 해금
- 전투 덱은 네 칸이며 무작위 드로우 없이 장착한 네 패턴을 직접 선택
- 패턴 중복 획득, 패턴 레벨과 수치 강화 없음
- 위치와 시계방향 회전에는 추가 비용 없음

### 스테이지와 성장

- 일반 라이벌 8명과 최종 라이벌 1명
- 일반 라이벌 8명을 모두 격파하면 최종 라이벌 해금
- 최초 승리 보상: 대표 패턴, 라이벌 말랑이 스킨, 라이벌 점령 셀 스킨
- 클리어한 라이벌에게 제한 없이 재도전 가능
- 일반 라이벌 격파 수에 따라 라운드 말랑력 `6 → 8 → 10 → 12` 성장
- 해금 상태, 덱, 장착 스킨과 설정은 로컬 JSON으로 저장

### 전장

| 표시 | 내부 격자 | 라운드 |
| --- | ---: | ---: |
| 소형 | `18×28` | 10 |
| 중형 | `24×36` | 15 |
| 대형 | `30×45` | 20 |

- 라운드마다 양 진영에 정해진 말랑력 지급
- 한 라운드의 진화는 15세대
- 플레이어와 AI는 같은 패턴 비용과 생명 규칙 사용
- 각 진영은 상대 셀을 이웃 수에 포함하지 않고 독립적으로 `B3/S23` 적용
- 생명 셀이 죽어도 이미 점령한 영토는 남음
- 최종 영토 수가 같으면 현재 버전에서는 무승부

## 3. 전투 조작

전투 하단 조작부는 한 행으로 구성한다.

1. 장착한 패턴 네 개 중 하나를 직접 선택한다.
2. 회전 버튼으로 진행 방향을 시계방향 90도씩 바꾼다.
3. 전장을 터치해 말랑력을 소비하고 패턴을 배치한다.
4. 필요하면 `취소`로 이번 라운드의 마지막 배치를 되돌린다.
5. `진화`를 눌러 배치를 확정하고 자동 진화를 시작한다.

배치 취소 규칙:

- 이번 라운드에 배치한 패턴만 취소할 수 있다.
- 가장 최근 배치부터 한 단계씩 되돌린다.
- 생명층과 해당 배치로 바뀐 영토층을 배치 직전 상태로 복원한다.
- 해당 배치에 사용한 말랑력을 전액 돌려받는다.
- 취소할 배치가 없으면 버튼이 비활성화된다.
- 진화를 시작하면 해당 라운드의 취소 기록은 폐기된다.
- 픽셀아트 적용 전에는 `취소` 글자를 사용하며, 최종 자산은
  `art/ui/icons/undo_24.png`를 사용한다.

## 4. 구현된 화면과 흐름

현재 플레이스홀더 상태로 다음 흐름이 연결되어 있다.

```text
시작
→ 메인 메뉴
→ 라이벌 선택
→ 라이벌 상세
→ 덱·스킨 편성
→ 전투
→ 결과·최초 승리 보상
→ 재도전 또는 메인 복귀
```

추가로 구현된 화면과 기능:

- 자유 점령전: 전장 규모, 말랑력과 상대를 선택해 반복 플레이
- 수집함: 해금한 패턴, 라이벌과 스킨 현황 표시
- 설정: 음악, 효과음, 햅틱, 진화 속도와 진행 초기화
- 전투 결과: 승패, 점수, 첫 해금 보상, 재도전과 메인 복귀
- 스킨 적용 구조: 플레이어 말랑이와 점령 셀을 각각 장착하고 적 라이벌 테마 표시
- 실제 PNG가 지정된 경로에 들어오면 플레이스홀더를 자동으로 교체하는 자산 슬롯

## 5. 화면과 픽셀아트 기준

- 논리 해상도: `540×960`
- 방향: 세로 고정
- 화면 비율을 유지하면서 기기의 가용 영역을 채우는 분수 배율 사용
- 픽셀 텍스처 필터: Nearest
- 시작 화면의 별도 게임 로고는 사용하지 않고 배경 이미지에 포함
- 전투 회전, 취소와 진화 버튼은 최종적으로 `24×24` 픽셀아트 아이콘 사용
- 필요한 자산별 파일명과 원본 해상도는 `pixel_art_checklist.md`를 기준으로 제작

## 7. 현재 남은 작업

우선순위 순서:

1. `pixel_art_checklist.md`에 맞춰 픽셀아트 제작
2. 시작·메뉴 배경, 라이벌 일러스트와 스킨을 실제 자산으로 교체
3. 회전, 취소, 진화 등 전투 아이콘 적용
4. 실제 아트를 기준으로 화면 여백, 글자 크기와 버튼 크기 조정
5. 라이벌별 AI 난이도와 패턴 비용 밸런스 플레이 테스트
6. 사운드와 햅틱의 실제 자산·호출 연결
7. 최종 iOS 서명 빌드, 설치와 전체 터치 흐름 재검증

최종 실기기 테스트에서는 특히 다음을 확인한다.

- 네 패턴 선택, 회전, 연속 배치, 연속 취소와 말랑력 환급
- 취소 후 같은 위치에 다시 배치할 수 있는지
- 진화 시작 후 취소가 비활성화되는지
- 소형·중형·대형 전장에서 셀과 버튼이 충분히 보이는지
- 긴 라이벌 이름과 보상 문구가 잘리지 않는지
- 앱 재실행 후 해금, 덱과 스킨 상태가 유지되는지
